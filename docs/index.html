Mikan 3-Currency clr Index (MCI)

A PPP-based structural valuation framework applicable to any three currencies (this paper analyzes USD, JPY, and TRY) using centered log-ratio (clr) transformation from Compositional Data Analysis (CoDA).

PPP（購買力平価）を基準とした、任意の3通貨に適用可能な評価指標です（本論文ではUSD・JPY・TRYを分析）。組成データ解析（CoDA）のclr変換を用いて、ゼロサム制約下での通貨の過大評価・過小評価を分析します。

About MCI / MCIについて

The Mikan 3-Currency clr Index (MCI) is a novel currency valuation framework that:

  • Uses Purchasing Power Parity (PPP) as the equilibrium baseline
  • Applies centered log-ratio (clr) transformation from Compositional Data Analysis (CoDA)
  • Evaluates any three currencies in a zero-sum basket structure (this paper uses USD, JPY, and TRY)
  • Identifies currency over/undervaluation relative to PPP fundamentals

MCIは、任意の3通貨間（本論文ではUSD・JPY・TRY）の相対的な過大評価・過小評価を構造的に捉える汎用的な指標です。PPPを均衡基準とし、CoDAのclr変換を適用します。

月次データを用いた分析と価格推定については第8章を参照してください。
For monthly data analysis and price estimation, see Chapter 8.
